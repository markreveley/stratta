## Findings

- Each of the four checks fails when it should, in each of the three apps. Twelve of
  twelve.
- In `gui/` and `tui/`, a compile step also prints the warning seeded in `core/`,
  because both build core as a dependency. This run cannot say whether a warning that
  is only in core would fail their compile steps. It does not need to: core's own job
  fails on it.
- A second control ran the same morning for a different question, and is recorded in
  [the issue it belongs to](../issues/2026-11-28-ci-first-run.md): the branch
