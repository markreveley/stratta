## Findings

Filed as [`md/issues/2026-11-28-ci-first-run.md`](../issues/2026-11-28-ci-first-run.md):

1. Three tests pass only on a machine with a git identity. One failed here; two in
   `core/` were passing because a fourth test leaves an identity in the environment.
   Fixed at `986d034`, and
   [the run on that commit](https://github.com/markreveley/stratta/actions/runs/46127755300)
   passes: 23, 3 and 22 tests, no failures.
2. `core/` has no lock file, which is why the two jobs above fetched different commits
   of Harness.
3. Elixir 1.20 reports three warnings that 1.19 does not.

Apart from that one test, the code as it stood passes its gate on the versions it
requires: it compiles with no warning, it is formatted, and 47 of 48 tests pass.
