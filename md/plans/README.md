# plans/

One folder per plan. Each plan's status is on the line under its title. One is accepted, the plan to adopt PropertyDamage's method; one is dropped, the verification plan it replaced; the rest are proposed, and none is built except where `state.md` says so. A plan's frontmatter gives its `kind`, and its section *Why this exists* gives the evidence ([design commitments](../docs/design-commitments.md), 3). The phases that are scheduled, and their order, are in `next.md`.

Rules for this folder (what belongs here, naming, form): [repo-template](https://github.com/markreveley/repo-template/blob/main/template/md/plans/README.md).
